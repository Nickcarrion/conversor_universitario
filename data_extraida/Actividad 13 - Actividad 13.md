|    | Pregunta: ¿Puede considerarse la actividad recreativa de un parque de diversiones (safari, caza y pesca de animales salvajes) como una actividad agroindustrial?                                                                                                                                                                                                                                                                                                                                                                                                                                                               |                     |                                                                    |    |         |        |       |       |
|    | Respuesta: NO. La NIC 41 define la actividad agrícola como la gestión de la transformación biológica y la recolección de activos biológicos para destinarlos a la venta, convertirlos en productos agrícolas o en otros activos biológicos. En el parque, los animales se mantienen con fines de entretenimiento y recreación, no para obtener un producto agrícola ni para su venta; además, la caza y la pesca de animales no gestionados no constituyen actividad agrícola (NIC 41, párr. 6). Por lo tanto, no es una actividad agroindustrial y los animales del parque no califican como activos biológicos de la NIC 41. |                     |                                                                    |    |         |        |       |       |
